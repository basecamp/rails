# Action Text

Action Text brings rich text content and editing to \Rails. New applications use the [Lexxy editor](https://github.com/basecamp/lexxy), and applications upgraded from earlier versions of \Rails keep the [Trix editor](https://trix-editor.org), which Action Text continues to support through the `action_text-trix` gem. The editor handles everything from formatting to links to quotes to lists to embedded images and galleries. The rich text content generated by the editor is saved in its own RichText model that's associated with any existing Active Record model in the application. Any embedded images (or other attachments) are automatically stored using Active Storage and associated with the included RichText model.

You can read more about Action Text in the [Action Text Overview](https://guides.rubyonrails.org/action_text_overview.html) guide.

## Development

The JavaScript for Action Text is distributed both as a npm module under @rails/actiontext and via the asset pipeline as actiontext.js. To ensure that the latter remains in sync, you must run `yarn build` and check in the artifacts whenever the JavaScript source changes. The editors' JavaScript and stylesheets come from their own gems: `lexxy` and `action_text-trix`.
